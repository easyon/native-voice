WebSocket 与鉴权

    

      浏览器的 WebSocket API 不能自定义 Authorization 头。服务端
      auth.enabled=true 时，本页的麦克风/回放模式会以 4401 关闭；
      离线转写会正常携带 Bearer key。生产验收实时链路时请在受控内网临时关闭鉴权，
      或使用带自定义头的原生客户端。
    

    
实时事件

    
task-started
  → result-generated (sentence_begin=true, sentence_end=false)
  → result-generated (sentence_end=false)
  → result-generated (sentence_end=true, usage.duration)
  → task-finished

    

      sentence_id 从 1 递增；partial 的 end_time 为 null；
      句末 final 的 usage.duration 为任务累计音频秒数。超过
      partial_window_s 的长句不再返回 partial，但句末仍返回完整文本。
