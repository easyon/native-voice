    接入说明与限制
    
端点

    

      同步 / SSE：POST /api/v1/services/audio/tts/SpeechSynthesizer；
      SSE 需加 X-DashScope-SSE: enable。
      WebSocket：/api-ws/v1/inference，流程为
      run-task → task-started → continue-task → finish-task → task-finished，
      音频通过二进制帧返回。
    

    
本页如何使用

    

      model 和 voice 是服务端配置里的 key（本页从
      /readyz 读取），不是百炼别名。API Key 只保存在浏览器里，不会写到服务端。
    

    
WebSocket 与鉴权

    

      浏览器的 WebSocket API 不能自定义 Authorization 头。服务端
      auth.enabled=true 时，本页的 WebSocket 模式会以 4401 关闭，
      请改用同步/SSE 模式，或在内网验收时临时关闭鉴权。同步/SSE 会正常携带 Bearer key。
    

    
格式与播放

    

      PCM 按 16-bit 单声道实时调度播放；wav 流会剥掉首帧的 44 字节头；
      mp3 流在支持 MediaSource 的浏览器上边收边播，否则收完后整段播放。
      opus 不能用于流式，只能走同步。流式时 pitch 必须为 1.0。
